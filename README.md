# 🧠 Sentiment Analysis Web Application

A machine learning-powered web application that analyzes text and helps identify the sentiment expressed in user input.

🔗 **Live Demo:** [Try Sentiment Analysis](https://sentiment-analysis-rosy-ten.vercel.app/)

📂 **GitHub Repository:** [sentiment-analysis](https://github.com/Siddhesh030/sentiment-analysis)

---

## 📌 Project Overview

Sentiment Analysis is a Natural Language Processing (NLP) project designed to analyze textual data and identify the underlying sentiment. It demonstrates how machine learning and text processing techniques can be used to understand opinions, feedback, and emotions expressed through text.

The project provides a web-based interface for interacting with the sentiment analysis application.

## ✨ Features

- 🧠 **Sentiment Analysis:** Analyze text to understand its sentiment.
- 💬 **Text Processing:** Process user-provided text for sentiment prediction.
- 🌐 **Web Interface:** Access the application through a browser.
- ⚡ **Interactive Experience:** Submit text and view the analysis results.
- 📱 **Easy Accessibility:** Use the deployed application without manually setting up the project locally.

## 💻 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Python installed on your system
- Git
- pip package manager

### 1. Clone the Repository

```bash
git clone https://github.com/Siddhesh030/sentiment-analysis.git
```

### 2. Navigate to the Project Directory

```bash
cd sentiment-analysis
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment.

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

If `app.py` is the main Flask application, run:

```bash
python app.py
```

Open the local URL displayed in the terminal, commonly `http://127.0.0.1:5000/`.

> **Note:** Follow the entry point and deployment configuration defined in the repository if your project uses a different startup command.
